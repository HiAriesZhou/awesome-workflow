## Data & structure

| ID | Decision | Choice | Why |
|----|----------|--------|-----|
| S1 | Source of truth | One YAML file per workflow under `workflows/` | Diff-friendly, PR-reviewable, matches awesome contribution UX |
| S2 | Schema | JSON Schema Draft-07 in `schema/workflow.schema.json` | CI + local `npm run build` validate before README/site emit |
| S3 | README | Generated by `scripts/build.mjs` from YAML | Avoid dual maintenance (awesome list + site) |
| S4 | Site data | Build emits `src/data/workflows.json` | Static Pages friendly; no runtime YAML parse in browser |
